# 01. Descripción General del Proyecto

## Sistema de Gestión de Productos y Ventas para una Pizzería

### Descripción del proyecto

Desarrollo de una aplicación de escritorio para administrar productos,
registrar ventas y consultar estadísticas comerciales de una pizzería o negocio.

El sistema permitirá centralizar las operaciones del negocio,
automatizar cálculos y facilitar el acceso a la información.

---

### Objetivo general

Desarrollar un sistema que simplifique la gestión comercial de una pizzería,
reduzca errores manuales y facilite el seguimiento de las ventas.

---

### Funcionalidades principales

- **Productos:** alta, baja, modificación, consulta y organización por categorías.
- **Ventas:** registro de pedidos, cálculo de importes y generación de comprobantes.
- **Pagos:** registro de pagos en efectivo o Mercado Pago y cálculo del vuelto.
- **Envíos:** cálculo del costo según la distancia y la tarifa configurada.
- **Estadísticas:** consulta de productos más vendidos, ingresos y ventas por períodos.
- **Usuarios:** inicio de sesión y permisos según el perfil.

---

### Usuarios del sistema

#### Administrador

- Gestionar productos, categorías, precios y usuarios.
- Configurar tarifas de envío.
- Registrar ventas.
- Consultar estadísticas y reportes.

#### Usuario normal

- Consultar productos.
- Registrar pedidos y ventas.
- Registrar pagos y calcular envíos.
- Generar comprobantes.

---

### Tecnologías utilizadas

| Tecnología | Descripción |
|------------|-------------|
| **C#** | Lenguaje de programación |
| **Windows Forms** | Interfaz gráfica |
| **SQL Server** | Base de datos |
| **Arquitectura de tres capas** | Presentación, Negocio y Datos |

---

### Alcance general

El sistema gestionará productos terminados, ventas, pagos,
envíos y estadísticas comerciales.

No incluirá administración de materias primas, recetas
ni control de ingredientes.
