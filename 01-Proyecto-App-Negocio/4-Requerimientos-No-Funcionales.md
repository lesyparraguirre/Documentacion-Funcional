# 04. Requerimientos No Funcionales

## Sistema de Gestión de Productos y Ventas

### 1. Objetivo

Definir las condiciones de calidad, seguridad y rendimiento
que deberá cumplir el sistema.

---

### 2. Requerimientos no funcionales

| ID | Requerimiento | Descripción |
|---|---|---|
| RNF-001 | Rendimiento | Las operaciones habituales deberán responder en un máximo de 3 segundos bajo condiciones normales. |
| RNF-002 | Seguridad | Las contraseñas deberán almacenarse de forma segura y el acceso estará restringido según el perfil del usuario. |
| RNF-003 | Usabilidad | La interfaz deberá ser clara, intuitiva y fácil de utilizar. |
| RNF-004 | Compatibilidad | La aplicación deberá funcionar en Windows. |
| RNF-005 | Integridad de datos | El sistema deberá validar los datos ingresados y evitar registros inconsistentes. |
| RNF-006 | Persistencia | La información deberá almacenarse en SQL Server. |
| RNF-007 | Mantenibilidad | El código deberá organizarse mediante una arquitectura de tres capas. |
| RNF-008 | Manejo de errores | El sistema deberá mostrar mensajes claros ante errores y evitar cierres inesperados. |
| RNF-009 | Disponibilidad | El sistema deberá funcionar mientras la aplicación y la base de datos estén disponibles. |
| RNF-010 | Precisión | Los importes monetarios deberán calcularse y almacenarse con precisión decimal. |

---

### 3. Tecnologías utilizadas

- **Lenguaje:** C#.
- **Interfaz:** Windows Forms.
- **Base de datos:** SQL Server.
- **Arquitectura:** tres capas.
- **Plataforma:** Windows.
