# 01. Descripción General del Proyecto
Sistema de Gestión de Productos y Ventas.
Descripción del proyecto
El proyecto consiste en el desarrollo de una aplicación de escritorio destinada a la administración de productos y la gestión de ventas de un comercio.
El sistema será genérico y adaptable a diferentes tipos de negocios, permitiendo centralizar la información comercial en una base de datos.
La aplicación contará con funcionalidades para administrar productos, registrar operaciones de venta, gestionar métodos de pago, calcular costos de envío y generar comprobantes de compra.
Problemática identificada
Los comercios que realizan la administración de productos y ventas mediante registros manuales o herramientas no integradas pueden presentar dificultades como:
•	Errores en el registro de productos y precios.
•	Demoras en el cálculo de importes y costos de envío.
•	Falta de centralización de la información.
•	Dificultades para consultar operaciones realizadas.
•	Errores en la generación de comprobantes de venta.
Objetivo general
Desarrollar una aplicación de escritorio que permita centralizar y optimizar la administración de productos y el proceso de ventas, facilitando las operaciones comerciales y reduciendo los errores asociados a los registros manuales.
Objetivos específicos
•	Permitir el alta, baja, modificación y consulta de productos.
•	Facilitar la búsqueda de productos mediante diferentes criterios.
•	Automatizar el cálculo de los importes de venta.
•	Registrar operaciones realizadas mediante distintos métodos de pago.
•	Calcular los costos de envío según la distancia y la tarifa configurada.
•	Generar comprobantes con el detalle de las operaciones.
•	Administrar los permisos de acceso según el tipo de usuario.
•	Almacenar la información en una base de datos.
Usuarios del sistema
Administrador: responsable de gestionar productos, usuarios, precios y configuraciones generales del sistema.
Usuario normal: responsable de registrar ventas, procesar pagos y generar comprobantes.
Tecnologías utilizadas
•	Lenguaje de programación: C#.
•	Interfaz gráfica: Windows Forms.
•	Base de datos: SQL Server.
•	Arquitectura: tres capas.
